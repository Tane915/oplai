# OPLAI · OPC Link AI

> 单人成链，智流自驱 — One Merchant, Linked AI

面向一人商家（One Person Company）的 AI 自动化链路工具。用智能体、知识库与自动化工作流，把商品、客户、内容、订单串成一条会自己跑起来的链路。

## 关于这个仓库

这是 OPLAI 的产品介绍页 —— 单文件、零依赖、可离线打开。

- `index.html` 一个文件装下全部：HTML、CSS、内联 SVG 图标与交互脚本
- 全站中英双语切换，记住语言选择，同步页面标题与 meta 描述
- 响应式布局，移动端适配
- 唯一的网络依赖是标题字使用的 Orbitron（Google Fonts），断网自动回退系统字体

## 本地查看

直接双击 `index.html`，或起一个静态服务：

```bash
python -m http.server 8080
# 打开 http://127.0.0.1:8080/index.html
```

## 配置

下载弹窗的网盘链接集中在主脚本顶部：

```js
var DOWNLOAD_LINKS = {
  baidu: { url: '', code: '' },
  quark: { url: '', code: '' }
};
```

填入链接（和可选提取码）后，按钮自动变为可点击；留空时显示「即将开放」并禁用，避免跳到无效地址。
